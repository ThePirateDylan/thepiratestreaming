# Sidebar icon replacements

Drop replacement PNG files in this folder, keeping the exact filenames below. The skin loads these files directly from `repo/skin.pirate/shortcut-icons/`.

| File | Sidebar item |
|---|---|
| `home.png` | Home |
| `search.png` | Search |
| `tvshows.png` | TV Shows |
| `tvguide.png` | Live TV / TV Guide |
| `movies.png` | Movies |
| `favorites.png` | My Stars (Kodi Favorites) |
| `cloud.png` | Cloud Services |
| `settings.png` | Settings |

Use transparent 64×64 RGBA PNGs for the best fit. Keep these filenames when replacing artwork; no skin XML edits are needed.
